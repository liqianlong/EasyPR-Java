## Convert

Utilities to convert between BytePointer/byte[] and primitives.

Package: `org.easypr.util`

### Public API

- `static float toFloat(BytePointer)` / `static double toDouble(BytePointer)`
- `static int toInt(BytePointer)` / `static long toLong(BytePointer)`
- `static byte[] getBytes(float|double|int|long)`
- `static int toInt(byte[])` / `static long toLong(byte[])`
- `static double toDouble(byte[])` / `static float toFloat(byte[])`
